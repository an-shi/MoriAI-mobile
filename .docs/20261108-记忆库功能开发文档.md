# 记忆库功能开发文档

> 文档日期：2026-11-09  
> 文档范围：角色长期记忆的自动提炼、持久化、检索召回、人物小档案、未完成话题、群公共记忆和群印象  
> 当前状态：已实现单聊长期记忆、人物小档案、未完成话题，以及按群隔离的群公共记忆和群印象；默认开启自动整理

## 1. 功能概览

记忆库按角色卡分别保存长期记忆，角色在后续单聊和主动消息中可以自然想起这些事：

- 用户明确表达过的身份、称呼、稳定喜好和边界；
- 用户的长期计划、约定和重要经历；
- 用户和角色之间的关系、相处模式；
- 用户最近反复提到、值得长期保留的事情。

除了逐条记忆，记忆库还会为每个角色维护一份关于对方的人物小档案，记录对方是谁、稳定喜好、最近状态和重要日期；同时记录还没有结果的未完成话题，方便角色在后续聊天里自然追问。

群聊也有独立的群公共记忆和群印象：只从对应群的聊天里提炼大家共同经历、共同计划、共同话题和群氛围，并且只在那个群里召回，不会进入单聊或其他群。

记忆不会保存完整聊天记录。后台会从聊天中提炼一句一条的事实，经过过滤、去重和合并后写入记忆库。

入口：

```text
「记忆与角色卡」Tab
  └── 记忆
      ├── 搜索 / 按角色筛选
      ├── 添加、编辑、删除记忆
      ├── 立即整理记忆
      └── 记忆设置
          ├── 启用长期记忆
          ├── 自动整理开关
          ├── 启用群聊公共记忆
          ├── 召回条数
          ├── 整理闲置时间和最少消息数
          └── 每个角色最多记忆数
  └── 人物档案
      ├── 查看每个角色的对方小档案
      ├── 手动编辑档案
      └── 添加、编辑、标记解决和删除未完成话题

群聊设置
  └── 群公共记忆
      ├── 查看和编辑群印象
      ├── 搜索、添加、编辑和删除公共记忆
      ├── 立即整理
      └── 清空群公共记忆
```

## 2. 参考 AuraBot

AuraBot 的记忆库设计包含：

- 本地 JSON 持久化；
- 中文二元字组 + 英文词的倒排索引；
- BM25 关键词检索，叠加「关于当前说话人」「重要程度」「新近程度」权重；
- 自动从聊天中提炼事实，和旧记忆比对后新增、补充或标成过时；
- 遗忘曲线和容量清理；
- 人物小档案、群印象、相处经验和说话方式；
- 群聊 / 非主人私聊的隐私范围过滤；
- 面板查看、搜索、编辑、删除和恢复。

Mori 当前实现的是第一阶段的「核心记忆库」：

- 已实现中文二元字组关键词检索、重要性和新近程度加权；
- 已实现自动提炼、去重、合并和冲突处理；
- 已实现人物小档案：对方身份、关系、稳定喜好、最近状态和重要日期；
- 已实现未完成话题：自动识别、手动维护、解决归档和后续召回；
- 已实现按角色隔离、单聊召回、设置页和记忆管理页面；
- 已实现群公共记忆和群印象：按群隔离提炼、只在对应群召回；
- 暂未实现向量检索、相处经验和遗忘曲线；
- 当前单聊记忆只从单聊提炼，群聊公共记忆只从群聊提炼，两者互不串用。

## 3. 数据模型

文件：`lib/models/memory.dart`

### 3.1 `MemoryEntry`

| 字段 | 说明 |
|---|---|
| `id` | 记忆 ID |
| `characterId` | 所属角色卡 ID |
| `text` | 一句话记忆，最多 300 字 |
| `category` | `fact` / `preference` / `relationship` / `plan` / `event` / `impression` |
| `importance` | 重要性 0-1 |
| `tags` | 最多 5 个标签 |
| `source` | `auto` 自动整理 / `manual` 手动添加 |
| `conversationId` | 来源会话；当前为角色单聊 ID |
| `aboutName` | 关于谁；当前主要是用户名称 |
| `createdAtMs` | 创建时间 |
| `updatedAtMs` | 最后更新时间 |
| `lastAccessedAtMs` | 最后一次被召回的时间 |
| `accessCount` | 被召回次数 |
| `isActive` | 是否仍有效；冲突旧记忆会归档 |
| `archivedAtMs` | 归档时间 |

分类文案：

| 值 | 文案 |
|---|---|
| `fact` | 事实 |
| `preference` | 喜好 |
| `relationship` | 关系 |
| `plan` | 计划 |
| `event` | 经历 |
| `impression` | 印象 |

### 3.2 `MemorySettings`

| 字段 | 默认值 | 说明 |
|---|---|---|
| `enabled` | `true` | 是否启用长期记忆和召回 |
| `autoExtract` | `true` | 是否自动从单聊提炼记忆 |
| `recallCount` | `6` | 每次最多召回条数；0 关闭，最多 20 |
| `extractIdleMinutes` | `10` | 聊天闲置多少分钟后开始整理 |
| `extractMinMessages` | `8` | 新消息达到多少条才整理 |
| `maxMemoriesPerCharacter` | `500` | 每个角色最多保留记忆数；超过后优先清理低重要性自动记忆 |

### 3.3 `MemoryExtractionState`

用于断点续整理，避免重复调用模型：

| 字段 | 说明 |
|---|---|
| `lastProcessedMessageId` | 最近处理到的消息 ID |
| `lastProcessedAtMs` | 最近一次整理时间 |
| `lastError` | 最近一次失败原因 |
| `nextRetryAtMs` | 失败后的最早重试时间 |

### 3.4 `MemoryProfile`

人物小档案，每个角色一份。

| 字段 | 说明 |
|---|---|
| `characterId` | 所属角色卡 ID |
| `summary` | 对方是谁、身份和与角色的关系，最多 300 字 |
| `preferences` | 稳定喜好、不喜欢和习惯，最多 300 字 |
| `recentFocus` | 最近的重要状态、计划或正在忙的事，最多 300 字 |
| `importantDates` | 重要日期或约定，最多 5 条，每条最多 40 字 |
| `updatedAtMs` | 最后更新时间 |

### 3.5 `MemoryOpenTopic`

未完成话题，每个角色最多保留 50 条。

| 字段 | 说明 |
|---|---|
| `id` | 话题 ID |
| `characterId` | 所属角色卡 ID |
| `text` | 一句话描述，最多 200 字 |
| `status` | `open` 待跟进 / `resolved` 已解决 |
| `importance` | 重要性 0-1 |
| `createdAtMs` | 创建时间 |
| `updatedAtMs` | 最后更新时间 |
| `resolvedAtMs` | 标记为解决的时间 |

### 3.6 `GroupMemoryEntry`

群公共记忆，每个群独立保存，最多 300 条。

| 字段 | 说明 |
|---|---|
| `id` | 记忆 ID |
| `groupId` | 所属群聊 ID |
| `text` | 一句话群公共记忆，最多 300 字 |
| `category` | `fact` / `preference` / `relationship` / `plan` / `event` / `impression` |
| `importance` | 重要性 0-1 |
| `tags` | 最多 5 个标签 |
| `source` | `auto` / `manual` |
| `createdAtMs` | 创建时间 |
| `updatedAtMs` | 最后更新时间 |
| `lastAccessedAtMs` | 最后一次被召回的时间 |
| `accessCount` | 被召回次数 |
| `isActive` | 是否仍有效 |
| `archivedAtMs` | 归档时间 |

### 3.7 `GroupMemoryProfile`

群印象，每个群一份。

| 字段 | 说明 |
|---|---|
| `groupId` | 所属群聊 ID |
| `summary` | 群是什么样、成员之间的氛围和关系，最多 300 字 |
| `sharedHabits` | 群里反复出现的共同话题、梗和相处习惯，最多 300 字 |
| `recentFocus` | 群里最近在忙的事、共同计划或近况，最多 300 字 |
| `importantDates` | 群里的重要日期或约定，最多 5 条 |
| `updatedAtMs` | 最后更新时间 |

## 4. 存储

文件：`lib/services/memory_store.dart`

| SharedPreferences Key | 内容 |
|---|---|
| `memory_settings_v1` | 全局记忆设置 |
| `character_memory_v1` | 按角色保存的记忆列表 |
| `memory_state_v1` | 每个角色的整理进度和重试状态 |
| `character_memory_profile_v1` | 按角色保存的人物小档案 |
| `character_memory_topics_v1` | 按角色保存的未完成话题 |
| `group_memory_v1` | 按群保存的群公共记忆 |
| `group_memory_state_v1` | 每个群的整理进度和重试状态 |
| `group_memory_profile_v1` | 按群保存的群印象 |

规则：

- 记忆按角色隔离，单聊和主动消息只能看到自己的角色记忆；
- 每个角色最多保留 `maxMemoriesPerCharacter` 条，默认 500；
- 超过容量时优先清理低重要性的自动记忆，手动记忆尽量保留；
- 设置损坏不会清空记忆列表；
- 记忆列表、人物档案或未完成话题损坏时会尽量跳过坏记录；
- 删除角色卡会同时删除该角色的记忆、人物档案、未完成话题和整理进度；
- 删除角色卡不会删除群公共记忆，因为群公共记忆属于群而不是某个角色；
- 清空聊天记录不会删除记忆、人物档案、未完成话题或群公共记忆，因为它们属于独立长期数据；
- 清空群公共记忆只影响该群，不删除聊天记录。

## 5. 自动提炼

文件：`lib/services/memory_service.dart`  
生成器：`lib/services/memory_extractor.dart`

### 5.1 触发条件

- 记忆总开关开启；
- 自动整理开启；
- 已配置模型和 API Key；
- 单聊最后一条消息已经超过 `extractIdleMinutes`；
- 自上次整理后至少有 `extractMinMessages` 条新消息；
- 上次失败后的重试时间已到；
- 当前没有正在整理同一个角色。

服务每 60 秒检查一次，每轮最多整理一个角色，避免同时发起多个模型请求。应用恢复时会补检查一次。

### 5.2 断点

- 每个角色保存 `lastProcessedMessageId`；
- 一次最多处理 40 条消息；
- 整理成功后前进游标，即使模型认为没有值得记的内容也会前进；
- 整理失败不前进游标，30 分钟后重试；
- 找不到旧游标时从最近 40 条消息重新开始，依靠本地去重避免重复写入。

### 5.3 提炼提示词

模型只负责从聊天素材中提炼，不直接决定权限或隐私范围：

- 只记录关于用户的身份/称呼、稳定喜好、重要关系、长期计划、约定、重要经历、相处模式和明确边界；
- 不记录寒暄、重复、临时情绪、一次性琐事、角色自己的设定和无信息量内容；
- 不记录密码、验证码、银行卡、身份证、API Key 等敏感信息；
- 每条一句话，主语写清楚，最多 6 条；
- 同时更新人物小档案：对方是谁、稳定喜好、最近状态和重要日期；没有变化的字段留空；
- 同时整理未完成话题：约定、等待结果、用户说以后再聊、未完成计划；已有话题带 ID，解决后输出 `resolved`；
- 输出 JSON 对象，包含 `memories`、`profile` 和 `openTopics`；兼容只输出记忆数组的旧格式。

### 5.4 本地校验与去重

- 文本长度 4-300 字；
- 过滤敏感词和明显的提示词注入内容；
- 用中文二元字组 Jaccard 相似度判断是否像同一条事实；
- 相似且不冲突：合并到旧记忆，保留更长的文本、较高的重要性和标签并集；
- 相似但冲突：新记忆重要性不低于旧记忆时，归档旧记忆并写入新记忆；
- 旧记忆重要性更高时，忽略这条低置信度新记忆；
- 没有任何匹配时新增记忆。

### 5.5 群聊公共记忆

文件：

- `lib/services/group_memory_extractor.dart`
- `lib/services/group_memory_service.dart`
- `lib/services/group_memory_store.dart`

触发条件与单聊一致：记忆总开关开启、群聊公共记忆开启、自动整理开启、已配置模型、群最后一条消息超过闲置时间、新消息达到最少消息数、没有正在整理同一个群。服务每 60 秒检查一次，每轮最多整理一个群。

提炼规则：

- 只从当前群聊的聊天记录提炼，不读取任何单聊；
- 素材会标记每条消息的发送者，用户和不同 AI 成员可以区分；
- 只记录群公共信息：共同经历、共同计划或约定、共同话题和梗、群氛围、成员相处方式、群里公开的重要日期；
- 不记录单聊私事、只对某个人说的秘密、敏感信息、临时情绪、寒暄和角色自己的设定；
- 同时更新群印象：群氛围、共同话题、最近在聊和重要日期；
- 输出 JSON 对象，包含 `memories` 和 `profile`，兼容只输出数组的旧格式。

去重、合并、冲突归档复用与单聊相同的本地相似度逻辑；群公共记忆每个群最多 300 条，超过后优先清理低重要性的自动记忆。

## 6. 检索与召回

文件：

- `lib/utils/memory_search.dart`
- `lib/services/memory_context_builder.dart`

### 6.1 检索

- 中文连续文本拆成二元字组，英文和数字按词；
- 使用 BM25 计算关键词相关度；
- 叠加重要性权重；
- 叠加新近程度 / 访问次数形成的保留强度；
- 只检索当前角色、仍然有效的记忆；
- 查询没有关键词时，使用高重要性记忆作为兜底；
- 人物小档案和最多 3 条未完成话题会随记忆一起注入，不受关键词检索影响；召回条数设为 0 时全部关闭。

### 6.2 召回范围

- 单聊：召回当前角色自己的记忆、人物档案和未完成话题；
- 主动消息：使用与单聊相同的召回范围；
- 群聊：只召回当前群的群公共记忆和群印象，不读取单聊记忆、人物档案或未完成话题；
- 其他群：不会读取当前群或其他群的公共记忆；
- 动态和动态评论：当前不注入任何记忆，避免公开内容泄露私人信息。

### 6.3 注入格式

```text
（以下是你长期记得的关于对方的事，不是对方刚说的。只在自然相关时使用，可以顺口提起，但不要逐条复述，也不要编造。）
【人物小档案】
- 对方是谁：用户是住在杭州的设计师
- 稳定喜好：喜欢睡前喝热牛奶
【还没结果的事】
- [待跟进 · 3 天前] 用户下周要去看牙医，还没告诉我结果
- [喜好 · 昨天] 用户喜欢在睡前喝热牛奶
- [计划 · 3 天前] 用户下个月准备去旅行
```

每次召回后更新 `lastAccessedAtMs` 和 `accessCount`，让经常被想起的记忆保留得更久。

群聊召回格式：

```text
（以下是你长期记得的这个群里的公共事情和群印象，不是用户刚说的。只在自然相关时使用，可以自然带出，但不要逐条复述，也不要编造。）
【群印象】
- 群氛围：大家像大学宿舍室友一样熟
- 共同话题：经常互相发梗图和深夜吐槽
- 最近在聊：最近在约一起看展
【群公共记忆】
- [计划 · 3 天前] 大家约好下个月一起去看展
```

## 8. 隐私与边界

- 记忆只保存在本机 SharedPreferences；
- 单聊记忆、人物档案和未完成话题不会注入群聊；
- 群公共记忆和群印象只从对应群提炼，只在该群召回，不进入单聊或其他群；
- 记忆提炼会过滤密码、验证码、银行卡、身份证、API Key 等敏感信息；
- 记忆提炼会拒绝明显的提示词注入内容；
- 删除角色卡会级联删除该角色的记忆、人物档案和未完成话题，但不会删除群公共记忆；
- 手动清空记忆立即生效，同时清空该角色的人物档案和未完成话题；
- 记忆、人物档案、未完成话题和群公共记忆不会自动写回聊天记录，也不会修改角色卡人设；
- 自动整理每次会调用一次当前模型，角色或群越多、聊天越多成本越高。

## 9. 已知限制

- 单聊记忆和群公共记忆分别提炼、分别召回，暂不支持把单聊事实整理成群公共记忆；
- 群公共记忆只从群聊提炼，群聊不读取单聊记忆、人物档案或未完成话题；
- 暂不支持向量检索，只使用关键词和重要性；
- 暂不支持相处经验和说话习惯；
- 人物小档案、未完成话题和群印象由模型在整理记忆时一起更新，没有变化时不会覆盖已有内容；
- 未完成话题最多保留 50 条，群公共记忆每个群最多 300 条；
- 暂不支持遗忘曲线，超过容量时按重要性和来源清理；
- 暂不支持导入/导出记忆、人物档案、未完成话题或群公共记忆；
- 暂不支持召回日志和调试面板；
- 记忆、人物档案、未完成话题和群公共记忆只影响系统提示词，不会直接生成固定句式；
- 首次整理从最近 40 条消息开始，不会回溯全部历史聊天。
