# Mori 项目技术架构说明

> 文档日期：2026-11-07  
> 项目名称：Mori（`mori_ai`）  
> 当前版本：1.0.0+1

## 1. 项目简介

Mori 是一个使用 Flutter 开发的移动端 AI 陪伴助手，包含「对话」「记忆与角色卡」「动态」三个主页面，设置从用户资料抽屉进入，通过 OpenAI 兼容协议接入大模型服务。当前内置 DeepSeek 供应商，底层按多供应商结构设计；对话页支持文本与图片消息，并支持自动消息、心情和每日日记。

- 目标平台：Android、iOS
- 包名：`com.moriai.mori_ai`
- 应用名称：Mori

## 4. 核心模块技术说明

### 4.1 `lib/main.dart`

- 调用 `WidgetsFlutterBinding.ensureInitialized()`。
- 并行加载 `ApiKeyStore`、`ModelStore`、`ThemeStore`。
- 使用 `ValueListenableBuilder<ThemeMode>` 监听主题。
- 使用 `ColorScheme.fromSeed`，主色 `0xFF6B9080`。
- 启用 Material 3，支持浅色 / 深色主题。

### 4.2 `lib/config/`

| 文件 | 技术内容 |
|---|---|
| `mori_config.dart` | `MoriConfig.systemPrompt` 系统提示词常量 |
| `model_providers.dart` | `ModelProvider` 数据结构、`ModelProviderCatalog` 供应商目录 |

`ModelProvider` 字段：

| 字段 | 说明 |
|---|---|
| `id` | 供应商标识 |
| `name` | 展示名称 |
| `baseUrl` | API 根地址 |
| `apiKeyHint` | Key 输入提示 |
| `description` | 设置页描述 |
| `modelsPath` | 模型列表路径，默认 `/models` |
| `chatPath` | 对话路径，默认 `/chat/completions` |
| `supportsThinkingToggle` | 是否支持 `thinking` 参数 |

当前供应商：`deepseek`，默认供应商 ID 为 `deepseek`。

### 4.3 `lib/models/`

| 文件 | 技术内容 |
|---|---|
| `chat_message.dart` | `ChatRole` 枚举、`ChatMessage` 消息模型、`ChatImage` 图片模型、多模态 `toApiJson()` |
| `model_option.dart` | `ModelOption` 模型信息与视觉能力标记 |
| `model_settings.dart` | `ModelSelection` 选择模型、`ModelPreset` 预设模型 |
| `diary.dart` | `DiarySettings`、`DiaryEntry`、`DiaryState` 与日期工具 |
| `memory.dart` | `MemoryEntry`、`MemorySettings`、`MemoryExtractionState`、`MemoryProfile`、`MemoryOpenTopic` |

- `ChatRole`：`user`、`assistant`。
- `ModelSelection`：`providerId` + `modelId`，实现 `==` / `hashCode`。
- `ModelPreset`：`id`、`name`、`selection`，支持 JSON 序列化与反序列化。
- `ChatImage`：图片字节与 MIME 类型，`dataUrl` 生成 base64 data URL。
- `ModelOption`：模型 `id`、`name`、`supportsVision`，用于图片能力判断。

### 4.4 `lib/pages/`

| 文件 | 技术内容 |
|---|---|
| `home_page.dart` | `Scaffold` + `IndexedStack` + Material 3 `NavigationBar` |

| `memory/memory_settings_page.dart` | 记忆开关、自动整理、召回和容量设置 |
| `memory/diary_page.dart` | 日记列表、心情/日期展示、删除与空状态 |
| `settings_page.dart` | 设置分组、`AnimatedBuilder` 多状态监听、子页面跳转 |

### 4.5 `lib/services/`

| 文件 | 技术内容 |
|---|---|
| `chat_service.dart` | 流式对话请求、SSE 解析、超时控制、HTTP 错误映射 |
| `model_list_service.dart` | `/models` 模型列表获取、JSON 兼容解析、去重排序、视觉能力识别 |
| `api_key_store.dart` | `FlutterSecureStorage` 按供应商保存 Key |
| `model_store.dart` | `SharedPreferences` 保存模型选择、预设与模型能力缓存 |
| `theme_store.dart` | `SharedPreferences` 保存主题模式 |
| `diary_store.dart` | 日记设置、角色日记和生成状态持久化 |
| `diary_context_builder.dart` | 把最近日记整理为单聊和主动消息上下文 |
| `diary_generator.dart` | 提炼当天有意义素材并生成第一人称日记 |
| `diary_service.dart` | 每日定时写作、凌晨补写、失败重试 |
| `memory_store.dart` | 按角色持久化长期记忆、人物档案、未完成话题和整理进度 |
| `memory_extractor.dart` | 从单聊提炼长期事实、人物档案和未完成话题 |
| `memory_service.dart` | 聊天闲置后自动整理、游标、合并和重试 |
| `memory_context_builder.dart` | 按当前消息检索并生成记忆上下文 |

技术要点：

- `ChatService` 支持注入 `http.Client`，测试使用 `MockClient.streaming`。
- `ModelListService` 支持注入 `http.Client`，测试使用 `MockClient`。
- Store 均为单例，通过 `ValueNotifier` 暴露状态。
- 网络超时：模型列表 20 秒，对话连接 30 秒，流式数据间隔 60 秒。
- 非 200 响应会解析 `error.message` 并转换为中文提示。
