# MoriAI UI 视觉规范

本次视觉改造以 Telegram 的简洁移动端体验为参考，同时保留 Mori 温柔、克制的品牌气质。所有页面、按钮、表单字段、导航与业务逻辑保持不变。

## 1. 品牌与色彩

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 品牌主色 | `#3F8F75` | `#8AD6B9` |
| 页面背景（奶白） | `#F7F4EC` | `#0F1512` |
| 应用栏 / 导航栏 | `#FFFDF8` | `#151D19` |
| 分组列表 | `#FFFFFF` | `#18211D` |
| 主文字 | `#1C2722` | `#E5ECE7` |
| 次要文字 | `#68756E` | `#A2B1A9` |
| 分隔线 | `#E5E1D7` | `#2B3731` |

- 主色只用于强调操作、选中态、图标底色和进度。
- 不使用高饱和渐变、粉色或大面积装饰色。
- 浅色背景保持奶白，深色背景使用低对比度的墨绿色，避免纯黑。

## 2. 字体与排版

- 中文优先使用系统字体（PingFang SC / Noto Sans SC / 微软雅黑），英文使用系统无衬线字体。
- 标题：19–20sp，`w700`。
- 列表标题：15.5–16.5sp，`w500–w600`。
- 正文：14.5–15.5sp，行高 1.45–1.55。
- 辅助文字：12.8sp，行高 1.45。
- 小标签：11sp，字距 0.1–0.4。

## 3. 圆角与间距

- 小组件圆角：10–12。
- 输入框 / 图标底色：14。
- 分组列表 / 内容卡片：18。
- 弹窗 / 底部面板：24。
- 聊天气泡：18，靠近发送者一侧的底角为 5。
- 页面左右留白：16。
- 分组之间留白：24。
- 列表行内边距：水平 14，垂直 9–12。

## 4. 组件规则

### 分组列表

- 使用 `MoriSettingsGroup`，一个分组一个连续表面，分组内使用低对比度分隔线，不给每个条目单独加卡片。
- 分组标题使用 `MoriSectionHeader`。
- 设置行使用 `MoriSettingsTile`：34×34 圆角图标底色 + 标题 + 说明 + 右侧箭头。
- 危险操作使用红色文字与 `MoriDangerButton` 确认按钮。

### 表单

- 输入框统一使用主题中的填充式圆角样式，聚焦时显示 1.4px 薄荷绿描边。
- 表单分组使用 `MoriFormSection`，标题、说明、字段之间保持固定节奏。
- 数字设置复用 `NumberSettingField`，不再单独覆盖边框。

### 聊天

- 聊天页使用 `MoriChatBackground` 的轻量叶纹壁纸。
- 消息列表使用 Flyer Chat 的 `ChatMessage` 作为消息外壳，负责收发对齐、间距与长按手势；消息内容仍由 Mori 自己的气泡组件渲染。
- 用户消息：薄荷绿气泡，无头像；AI 消息：奶白/深色气泡，头像只在一组消息的第一条显示。
- 每条消息内显示时间；跨 5 分钟或跨天显示独立时间标签。
- Markdown 支持粗体、删除线、行内代码和围栏代码块；代码块使用深色等宽字体区域。
- 底部输入区使用一体化圆角输入胶囊 + 圆形发送按钮，图片与表情入口收在胶囊内部。

### 聊天列表

- 不包裹卡片；头像 54，行高约 70。
- 名称、消息预览、时间、未读数分层清晰。
- 分隔线从头像右侧开始，长按菜单保留置顶操作。

### 弹窗与底部面板

- 统一 24 圆角、柔和遮罩、无多余阴影。
- 底部面板显示拖拽手柄。
- 危险操作统一使用红色确认按钮。

## 5. 图标

- 全局使用 Lucide 线性图标，统一通过 `MoriIcons` 访问。
- 图标尺寸：导航 22，操作 18–21，列表图标 16–20。
- 自动返回按钮通过 `ActionIconThemeData` 也使用 Lucide。

## 6. 组件库分工

- **Forui**：提供 `FTheme`、按钮组件与后续通用 UI 的基础。
- **Flyer Chat**：承载聊天消息外壳（对齐、间距、长按手势）。
- **Lucide Icons**：全局线性图标。
- **Flutter 原生 Widget**：聊天气泡、壁纸、列表、头像、表单等需要精细控制的自定义视觉。

## 7. 代码入口

- 主题与色板：`lib/ui/mori_theme.dart`
- 图标映射：`lib/ui/mori_icons.dart`
- 通用列表 / 表单 / 空状态 / 按钮：`lib/ui/mori_components.dart`
- 聊天壁纸：`lib/ui/mori_chat_background.dart`
- 消息 Markdown 渲染：`lib/widgets/mori_message_text.dart`
- 头像占位：`lib/widgets/avatar_fallback.dart`
